PHOTOS FOLDER

Put family photos here. Name each file after the person's number,
for example 12.jpg for person #12, then write the same path in that
person's "photo" field in family-data.js:

    photo: "photos/12.jpg",

Tips
- Use .jpg or .png, ideally square and under 1 MB.
- Names are case-sensitive once online: 12.JPG and 12.jpg are different files.
- Avoid spaces and accents in file names.

(This note also keeps the folder from disappearing on GitHub, which
does not store empty folders. You can leave it here.)
